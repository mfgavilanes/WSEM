# SPARQL — concept L1

Contenido del paquete

- `5-SPARQL-concept-L1-20.gift` contiene 20 preguntas GIFT de opción múltiple para Moodle.
- Los nueve pares `.dot`, `.mmd` y `.svg` corresponden a las preguntas con minigrafos RDF.
- Los SVG se han generado desde los ficheros DOT y tienen fondo transparente.

Para que Moodle muestre los gráficos, publica los SVG en la ruta indicada por cada elemento HTML del fichero GIFT.
