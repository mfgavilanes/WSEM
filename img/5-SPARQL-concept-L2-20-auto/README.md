# SPARQL — concept L2

Contenido del paquete

- `5-SPARQL-concept-L2-20.gift` contiene 20 preguntas GIFT para Moodle.
- Cada pregunta incorpora una figura SVG de apoyo. Los pares `.dot` y `.mmd` se incluyen como fuentes editables.
- Los SVG se han generado con fondo transparente.

Para que Moodle muestre los gráficos, publica los SVG en la ruta indicada en los elementos HTML del fichero GIFT.
